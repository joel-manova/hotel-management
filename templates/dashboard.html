💡 Why Queue for Room Allocation?

Data Structure Logic

In college hostels, fairness requires that the student who requested a room first must be the first one to receive it.

  • enqueue(): Student arrives when hostel is full → joins tail of queue.
  • dequeue(): Room released → head student receives it.
  • Time Complexity: Both operations are O(1) using collections.deque.

❌ Cancel Room Allocation

Auto FIFO Reallocation

When a student's room is cancelled, the room is released and the waiting queue is automatically polled. The first student (waiting_queue.popleft()) receives the room instantly.

🔍

⚙️ Automatic Cancellation Workflow:

  1. System removes the current occupant from allocated_students.
  2. Room is marked as released.
  3. System checks len(waiting_queue) > 0.
  4. If waiting students exist, it executes: student = waiting_queue.popleft().
  5. The freed room is assigned to that student immediately!
  6. If waiting queue is empty, the room joins available_rooms.append(room).

🧠 Data Structure Used

  • Data Structure: Queue (Linear Data Structure)
  • Core Principle: FIFO (First In → First Out)
  • Python Implementation: from collections import deque
  • Internal Architecture: Doubly Linked List block structure allowing O(1) appends and pops from both ends.

⚖️ Why Queue is Suitable for Hostel Allocation?

Students are allocated hostel rooms based strictly on their registration timestamp (order of arrival).

When rooms are full, placing applicants in a FIFO Queue guarantees fairness: the first student waiting will receive the next available room that gets freed.

"No student can skip ahead of earlier applicants, eliminating bias or starvation."

⚔️ Viva Voce Question: Why collections.deque instead of Python list?

Operation Python list Python collections.deque Explanation
Enqueue (append at rear) O(1) amortized O(1) Both append efficiently at the end.
Dequeue (pop from front) O(n) - SLOW O(1) - FAST list.pop(0) shifts every subsequent element left by 1 index in memory. deque.popleft() simply updates the head pointer.
Memory Model Contiguous array buffer Doubly-linked memory blocks deque is purpose-built for queues and double-ended queues.
